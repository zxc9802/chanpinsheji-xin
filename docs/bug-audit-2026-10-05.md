## 已修复

| 范围 | 可复现问题 | 修复 |
| --- | --- | --- |
| 作品删除 | 删除目录后，缓存仍能返回项目；另一窗口仍可尝试保存 | 删除统一经过存储层并清除缓存；删除后读取与保存返回 404 |
| 持久化 | 写盘失败却已更新内存和版本号 | 每项目串行更新；副本先落盘，成功后发布缓存 |
| 并发编辑 | 同一版本的并行请求存在覆盖窗口 | 同项目修改请求互斥，旧版本请求返回 409 |
| 简报保存 | 编辑后 700ms 内离开，延迟保存被取消 | 切换、新建和生成前真正提交未保存修改，并等待完成 |
| 电商方案保存 | 关闭后立即切换、保存中继续输入可能丢改动 | 保存串行化，按项目和编辑序号核对返回结果 |
| 多窗口电商编辑 | 轮询的新版本号可与旧表单混用 | 编辑器保留打开时的方案版本，防止旧表单覆盖新方案 |
| 项目切换 | 前一个项目的晚到响应、旧轮询可能覆盖当前项目 | 为加载与轮询增加请求代次和项目核对；切换时关闭旧弹层 |
| 上传提示 | Multer / JSON 解析错误返回 HTML 或通用 500 | 统一 JSON 错误响应，区分格式、数量和体积问题 |
| 图片上传 | 伪装为 image/png 的文字被当作参考图保存 | 在创建项目或保存素材前检查格式与文件签名 |
| XLSX | 只读共享字符串表，丢数字、顺序与 inlineStr 内容，还包含未使用旧字符串 | 改为逐工作表、逐行、逐单元格解析 |
| 文档解析 | 任意二进制文件被当作文字；PPTX 带属性的文本节点被漏掉 | 限定支持的文字格式，补充 PPTX 节点属性与实体解析 |
| 文件路径 | 文件名 `..` 等能解析到图片目录之外 | 限制公共素材路径的文件名格式 |
| 简报校验 | 部分简报对象能覆盖完整简报，随后编辑和导出崩溃 | 保存与生成前校验主要结构、列表、色值和面文案 |
| 重绘前置条件 | 没有简报或没有前序正视图也能排队重绘 | 校验简报与依赖图，未满足时明确返回错误 |
| 批量与单张任务 | 批次中尚未执行的排队图可被单独重绘；单张任务未结束就能开始新批次或删除项目 | 将排队、运行中、批次和实际任务状态统一纳入检查 |
| 历史版本 | 渲染中可切换定调图，干扰后续输入；失败后旧版本不易恢复 | 渲染中禁止切版本；错误卡可打开已有版本，选回后恢复为可用状态 |
| 图片展示 | 失败后恢复同一文件时，缓存的 src 导致 loaded 样式不恢复 | 清除未完成状态的 src 缓存标记 |
| 整套一致性 | 渲染中编辑简报或方案，后续图片使用新文案，整套混用两版 | 一批任务使用启动时的简报 / 方案快照 |
| 首图失败 | 首图失败仍提交其余依赖图片 | 包装与电商批次跳过依赖任务并显示原因；独立白底图仍可生成 |
| 下载成图 | HTTP 200 的错误 HTML 被保存为 PNG 并标记成功 | 落盘前检查实际图片签名 |
| 图片任务错误 | FAILED / CANCELLED 状态继续轮询直到超时 | 明确处理终止状态，并避免自动重复提交已被拒绝的任务 |
| 详情编辑 | 清空标题后保存，旧标题又恢复 | 区分空字符串与未提供字段 |
| 电商重绘参数 | 无效图片 ID 列表也能开启空任务 | 在修改状态前校验目标列表 |
| 详情文案 | 固定详情模块未复用主图的事实检查，无依据数字、价格和“待确认”可进入文案 | 补充可印刷文案过滤与数字核对；不改变固定屏数和模块顺序 |
| 重新构思 | 单方向回退时旧图未清理，且前端未接着生成 | 与新简报同步重置旧包装图，并启动单方向出图 |
| 启动 | 静态目录依赖终端 cwd；声明的 Node 最低版本低于 PDF 依赖要求 | 静态目录定位到源文件；同步 engines、启动检查和说明 |
| 真实文案模型 | 六面包装简报在 6,000 token 上限被截断，重试仍用同一预算 | 包装简报改为 16,000 token，保留完整结构校验 |
| 刷新时的任务恢复 | 文档解析状态只存在当前窗口，刷新后无法继续跟踪 | 持久化解析开始、完成及失败状态；重新打开项目后继续轮询并恢复方向选择 |
| 服务重启 | 解析与批次被中断后，计时和忙碌状态不能完整结束 | 启动恢复同时处理解析状态和批次结束时间，明确提示中断原因 |
| 进度提示 | 包装已完成时仍显示包装渲染中；备选屏因数量限制未采用也写成资料不足；读屏仍读到已完成图片的旧进度 | 区分包装完成与电商运行，准确描述备选屏未采用；完成后对辅助技术隐藏旧进度层 |
| 竞品详情屏 | 实际方案只要求本品成分信息，原模板却要求虚构普通竞品不足，生成了无依据的优劣对比 | 对 10/16 屏的竞品模块移除预设贬低文案，明确以已确认文字和对比资料为准；无对方资料时保留该屏并展示本品信息 |
